✅ Features Implemented
Tech Assessment #1 — Frontend
🔍 Search by city name, zip/postal code, GPS coordinates (lat,lon), or landmarks
📍 "Use My Location" via browser Geolocation API
🌡️ Current weather with temp, feels like, humidity, wind, pressure, visibility, cloudiness
🔄 °F / °C toggle for temperature units
🗓️ 5-Day Forecast with icons, high/low temps, precipitation chance
🌬️ Air Quality Index (AQI) with individual pollutant breakdown
⚠️ Error handling — invalid locations, API failures, GPS permission denied
📱 Fully responsive — works on desktop, tablet, and mobile
Tech Assessment #2 — Backend
📦 MongoDB + Mongoose for persistent data storage
CREATE — Save location + date range + weather data. Validates dates and geocodes location (fuzzy matching supported)
READ — View all saved records with search, pagination, and sorting
UPDATE — Edit notes, tags, and date range with full validation
DELETE — Remove records with confirmation dialog
📹 YouTube API — Videos of the searched location
🗺️ Google Maps API — Embedded map for the searched location
📤 Export in 5 formats: JSON, CSV, XML, Markdown, PDF
